ISTRUZIONI PER L'AVVIO DEL DATABASE E DELL'APPLICATIVO:

1. Creare un database vuoto su PostgreSQL (es. "unina_taskboard").
2. Eseguire lo script "database.sql" allegato per generare lo schema e i dati di test.
3. Nel progetto Java, aprire il file: src/control/DatabaseConnection.java.
4. Modificare le costanti USER e PASSWORD inserendo le credenziali del proprio server PostgreSQL locale.
